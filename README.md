# 房屋交易流程通知單（賣方版）

房仲交易流程與客戶進度分享工具，可直接部署於 GitHub Pages。

## 功能
- 填入案件基本資料、交易日期與款項
- 六大交易階段：簽約用印、領稅單、完稅、過戶設定、交屋、後續事項
- 每階段待辦勾選與自訂客戶提醒
- 自動儲存於瀏覽器 localStorage
- 客戶唯讀預覽
- 一鍵複製 LINE 文字
- 列印 / 存成 PDF
- 建立分享連結：資料放在網址 `#view=` fragment 內，不需後端資料庫

## 部署
將 `index.html` 發佈到 GitHub Pages 即可。

## 注意
這是流程提醒工具，不是法律、稅務或代書專業意見。實際日期、稅費與應備文件仍應依契約、代書、履保銀行及主管機關通知為準。


## 買方／賣方成交 LINE 文案產生器

新增頁面： [messages.html](./messages.html)

- 買方、賣方文字範本一鍵切換；欄位空白時保留空格線供填寫
- 輸入客戶稱呼、案件資料、代書、金額、各階段日期，右側即時預覽文字
- 買方：用印前確認貸款成數 → 用印 → 完稅 → 過戶 → 驗屋 → 預定交屋
- 賣方：簽約／用印 → 報稅 → 完稅 → 過戶 → 騰空 → 交屋
- 特殊事項（補簽約款、氯離子檢測、權狀交付、貸款排隊）可選填
- 一鍵複製 LINE 訊息，或下載 UTF-8 TXT
- 手機可操作，買方、賣方各自的資料獨立保留
- 無需資料庫或第三方服務，資料僅留在目前瀏覽器 localStorage

GitHub Pages 站點（需已設定從 main 根目錄發布）：
https://volcanofir.github.io/transaction-workflow/messages.html

所有款項、貸款預估、用印與完稅日期、驗屋安排及交屋作業，仍應以各案契約、代書及銀行最新進度為準。
