# 買方／賣方成交 LINE 通知產生器

這是房仲成交後，快速整理買方或賣方交易進度、產生 LINE 通知文字的靜態網頁工具。

## 網址

https://volcanofir.github.io/transaction-workflow/

舊版「賣方交易流程」表單已從首頁移除，首頁現在直接開啟買方／賣方成交通知產生器。
先前的 `messages.html` 連結會自動導向首頁。

## 功能

- 買方、賣方範本快速切換
- 填入稱呼、案件、地址、代書、日期、成交總價、貸款與付款金額
- 自動轉換為民國日期與星期
- 可勾選特殊事項，例如簽約款補款、氯離子檢測及銀行撥款提醒
- 即時預覽完整 LINE 文字，一鍵複製或下載 TXT
- 買方與賣方資料分開保存於目前瀏覽器
- 無需後端伺服器、資料庫或第三方 API

## 買方流程

簽約 → 用印前確認貸款成數 → 用印 → 完稅 → 過戶 → 驗屋 → 正式交屋。

## 注意

資料只保存在使用者裝置的瀏覽器，清除網站資料時可能遺失。實際款項、契約日期、稅務及銀行貸款進度仍以契約、代書與銀行通知為準。

## 部署

GitHub Pages 從 `main` 分支根目錄發佈 `index.html`，無需建置步驟。
